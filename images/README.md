# public/images/

Drop the generated cartoon-style scene images here with EXACTLY these filenames
(referenced by the build as `images/*.webp` — with `base: './'` they resolve
relative to the deployed page):

- `couple-hero.webp`    — hero portrait (cover ring)
- `couple-feeding.webp` — ek dusre ko khana khilate hue 🍬
- `varmala.webp`        — varmala pehnate hue 💐
- `haldi.webp`          — haldi lagwate hue ✨
- `mehndi.webp`         — mehndi lagwate hue 🌿
- `ghodi.webp`          — ghodi chadta dulha 🐴

Any image can also be swapped later from the admin panel (Images tab) with a
remote URL — no rebuild needed. If a file is missing, the site shows an
animated gradient fallback instead of a broken image.
